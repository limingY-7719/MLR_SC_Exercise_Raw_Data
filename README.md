Exercise-Induced Neural Plasticity in MLR and SC in Mice

Overview

This repository contains research data associated with the manuscript **"Exercise Induces Parallel Plasticity in the Mesencephalic Locomotor Region and Spinal Cord in Mice."**

The study investigates exercise-induced changes in neuronal excitability, persistent inward currents (PICs), and dendritic morphology in the mesencephalic locomotor region (MLR) and spinal cord (SC) of mice.

 Data Files

The repository includes four Excel datasets:

1. Neuronal excitability.xlsx**  
   Electrophysiological measurements of neuronal excitability and membrane properties in MLR and SC neurons.

2. Persistent inward current (PIC).xlsx
   Measurements of PIC onset voltage, amplitude, and related electrophysiological parameters.

3. Neuronal morphology.xlsx
   Quantitative measurements of dendritic morphology, including dendritic length, branching, and Sholl analysis.

4. Correlation analysis.xlsx 
   Data used to investigate relationships among neuronal excitability, PIC properties, and dendritic morphology.

Data Availability

The datasets are provided to support transparency, verification, and reproducibility of the findings reported in the manuscript.
